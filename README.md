# WordPress LDAP login wp fork

Расширенная версия бесплатной версии плагина [WordPress LDAP Login for Intranet Sites](https://plugins.miniorange.com/wordpress-ldap-login-intranet-sites) с поддержкой дополнительных полей пользователя и поддержкой интеграции с ALD Pro

## ✨ Особенности форка

Вырезаны "платные" не заполняемые поля
Добавлены атрибутов LDAP:
- **Фамилия**
- **Имя**
- **Отчество** 
- **Должность**

## 🛠 Установка

1. Скачайте репозиторий
2. В админ-панели WordPress:
   - Перейдите в `Плагины → Добавить новый`
   - Нажмите `Загрузить плагин`
   - Выберите скачанный ZIP-файл
3. Активируйте плагин

## ⚙ Настройка
После активации, в настройках плагина появятся новые поля

##🌍 Совместимость
WordPress: 5.0 и новее
PHP: 7.4+
LDAP-серверы:
-Active Directory
-OpenLDAP
-ALD Pro

Поддержка кириллических атрибутов
